# Tome Bioscience

Tome Biosciences is a genome-editing therapeutics company founded in 2021 and based in Watertown, Massachusetts. It develops programmable genomic integration (PGI) technology that pairs the site-specificity of CRISPR/Cas with integrase enzymes to insert genetic sequences of virtually any size into the genome without relying on double-strand DNA breaks. Cofounded by Omar Abudayyeh and Jonathan Gootenberg (formerly of MIT's McGovern Institute), the company raised roughly $213M across Series A and B financing, with a16z among its backers. Its programs target integrative gene therapies for monogenic liver diseases and cell therapies for autoimmune conditions.

This is a biopharmaceutical R&D company with no public API, developer portal, SDKs, or machine-readable API surface. Its documented website (tome.bio) does not currently resolve. It is tracked in the API Evangelist network as an a16z portfolio company / enrichment lead rather than an API producer.
